### A1 · ไอคอนปุ่ม "เพิ่ม" เปลี่ยนจากเส้นเป็นทึบ — 12 จุด
`Phase 3 ขั้น 3`

เดิมปุ่มเพิ่มบางจุดใช้ไอคอน **＋ แบบเส้น** บางจุด **＋ แบบทึบ** ตอนนี้ทุกจุดเป็น**ทึบ**เหมือนกันหมด

| # | หน้า | ทางเข้า | ปุ่มที่เปลี่ยน |
|---|---|---|---|
| 1 | **หน่วยนับ** | การผลิต & วัตถุดิบ → จัดการข้อมูลวัตถุดิบ → **หน่วยนับ** | ปุ่ม "เพิ่มหน่วย" ท้ายแต่ละกลุ่ม |
| 2 | **รอบพรีออเดอร์** (drawer รอบ) | สินค้า & คำสั่งซื้อ → จัดการรอบพรีออเดอร์ → แท็บ **รอบ** → คลิกรอบ | ปุ่ม "เพิ่มสินค้าในรอบ" |
| 3 | **รอบพรีออเดอร์** (modal สร้างรอบ) | 〃 → ปุ่ม "สร้างรอบใหม่" | ปุ่ม "เพิ่มแถวสินค้า" |
| 4 | **ใบสั่งผลิต** (modal) | การผลิต & วัตถุดิบ → จัดการข้อมูลการผลิต → ปุ่ม "สร้างใบสั่งผลิต" | ปุ่ม "เพิ่มแถวสินค้า" |
| 5 | **สูตร** (modal สูตรหลัก) | การผลิต & วัตถุดิบ → จัดการข้อมูลสูตร → "สร้างสูตรหลัก" | ปุ่ม "เพิ่มส่วนประกอบ" |
| 6 | **สูตร** (ตัวแก้วัตถุดิบ) | 〃 ใน modal เดียวกัน | ปุ่ม "เพิ่มวัตถุดิบ" |
| 7 | **สูตร** (ตัวแก้ขั้นตอน) | 〃 ใน modal เดียวกัน | ปุ่ม "เพิ่มขั้นตอน" |
| 8 | **ตั้งค่าหัวข้อรีวิว** | ภาพรวม → รายงานยอดขาย & ความคิดเห็น → รายงานความคิดเห็น → **ตั้งค่าหัวข้อรีวิว** | ปุ่ม "เพิ่มหัวข้อ" |
| 9 | **ข้อมูลร้าน** | พนักงาน → ข้อมูลร้าน | ปุ่ม "เพิ่มตลาดนัด" (ต้องกดแก้ไขก่อน) |
| 10 | **เพิ่ม/แก้สินค้า** | สินค้า & คำสั่งซื้อ → จัดการข้อมูลสินค้า → "เพิ่มสินค้า" | เครื่องหมาย ＋ ในกล่องอัปโหลดรูป |
| 11 | **จัดการแบนเนอร์** | พนักงาน → จัดการแบนเนอร์ → "เพิ่มแบนเนอร์" | ＋ ในกล่องอัปโหลดรูป |
| 12 | **บันทึกค่าใช้จ่าย** | ภาพรวม → การเงิน → บันทึกค่าใช้จ่าย → "เพิ่มรายจ่าย" | ＋ ในกล่องแนบใบเสร็จ |

**ควรเห็น:** ไอคอน ＋ ทึบเหมือนปุ่ม "เพิ่มสินค้า" / "สร้างคูปองใหม่" ที่หัวหน้ารายการ
**ถ้าเจอ:** ยังมีที่ไหนเป็นเส้นบาง ๆ อยู่ → แจ้ง

### A2 · ไอคอน 2 ปุ่มในประวัติแจ้งเตือน เปลี่ยนจากทึบเป็นเส้น
`Phase 3 ขั้น 3`

**ทางเข้า:** กด **กระดิ่ง 🔔** มุมขวาบน → **"ดูทั้งหมด"**

| ปุ่ม | เดิม | ตอนนี้ |
|---|---|---|
| "ทำเครื่องหมายอ่านแล้วทั้งหมด" | ✓ วงกลมทึบ | ✓ วงกลม**เส้น** |
| "ลบทั้งหมด" | 🗑 ทึบ | 🗑 **เส้น** |

กติกากำหนดว่ามีแค่ไอคอน "เพิ่ม" เท่านั้นที่เป็นทึบ ที่เหลือเป็นเส้นทั้งหมด — 2 ปุ่มนี้เคยผิดกฎ

### A3 · ปุ่ม "รีเซ็ต" ในหน้ารีวิว เปลี่ยนไอคอน
`Phase 3 ขั้น 2`

**ทางเข้า:** ภาพรวม → รายงานยอดขาย & ความคิดเห็น → **รายงานความคิดเห็น** → แถบกรองด้านบน

| | ไอคอน |
|---|---|
| เดิม | 🔄 ลูกศรหมุนวน (ซึ่งหมายถึง "ลองใหม่") |
| ตอนนี้ | ↩️ ลูกศรย้อนกลับ (ซึ่งหมายถึง "รีเซ็ต") |

**ควรเห็น:** ไอคอนเดียวกับปุ่ม "รีเซ็ต" ในหน้า **จัดการสิทธิ์การเข้าถึง** — ลองเปิดเทียบ

### A4 · รูป "ไม่มีข้อมูล" ในหน้าหน่วยนับ เปลี่ยนแบบ
`Phase 3 ขั้น 1`

**ทางเข้า:** การผลิต & วัตถุดิบ → จัดการข้อมูลวัตถุดิบ → **หน่วยนับ** → ดูกลุ่มที่ยังไม่มีหน่วย

| | รูป |
|---|---|
| เดิม | กล่องใหญ่แบบ default ของ antd |
| ตอนนี้ | รูปเล็กเรียบ — **แบบเดียวกับอีก 16 หน้าในระบบ** |

หน้านี้เคยเป็นที่เดียวที่ใช้รูปแบบ default

### A5 · สีข้อความเทาทั้งระบบ เข้มขึ้น — 106 จุด / 60 ไฟล์
`Phase 3 ขั้น 5`

**ทำไม:** เทาเดิม (`gray-400`) ได้คอนทราสต์ **2.54:1** ซึ่ง**ตกมาตรฐาน WCAG AA** (ต้อง 4.5:1) — คนสายตาไม่ดีอ่านไม่ออก
เปลี่ยนเป็น `gray-500` ได้ **4.83:1** ซึ่งเป็น**เทาอ่อนที่สุดที่ยังผ่าน**

> **วิธีทดสอบที่ได้ผลจริง:** หรี่ความสว่างจอลงครึ่งหนึ่ง แล้วดูว่าข้อความรองยังอ่านออกไหม
> ของเดิมจะเริ่มอ่านไม่ออกทันทีที่จอไม่สว่างเต็ม

| ปุ่ม · ช่องกรอก · ตาราง | 17px | **18px** |
| เมนูซ้าย · breadcrumb · ชื่อผู้ใช้ | 19.125px | **18px** ← **เล็กลง** |
| ข้อความย่อย (`text-sm`) | 15.75px | **16px** |
| ข้อความเล็กสุด (`text-xs`) | 14.6px | **16px** |
| หัวข้อ h1–h5 | 28–16px | **เท่าเดิม** |

> ⚠️ **เมนูซ้ายจะเล็กลง** — ไม่ใช่บั๊ก
> เดิมเมนูเขียนว่า 17px แต่**คำนวณผิด** ของจริงคือ 19.125px — เมนูจึงใหญ่กว่าเนื้อหาหลักมาตลอด
> ตอนนี้เมนูกับเนื้อหาเท่ากันที่ 18px ตามที่ตั้งใจไว้แต่แรก

### สิ่งที่ต้องจ้องเป็นพิเศษ — ช่องแคบที่ตั้งความกว้างตายตัว

ตัวอักษรโตขึ้น แต่ความกว้างเท่าเดิม → **ข้อความอาจล้นหรือโดนตัด** มี 13 จุด:

| หน้า | ส่วนที่ต้องดู |
|---|---|
| ตั้งค่าร้าน → เวลาเปิด-ปิด | ช่องเลือกเวลา (กว้าง 72px) — ดูว่า "08:00" แสดงครบไหม |
| แก้ไขสินค้า → ตัวเลือกเพิ่มเติม | ช่อง ต่ำสุด/สูงสุด (กว้าง 72px) และความยาวสูงสุด (80px) |
| โปรโมชัน → ราคาเฉพาะกลุ่ม | ช่องส่วนลด (64px) และจำนวนเงิน (70px) |
| โซนจัดส่ง · โซนขนส่ง | คอลัมน์ "ลำดับ" (70px) · "ค่าส่ง" (110px) |
| รายงานความคิดเห็น → การ์ดรีวิว | ตัวเลือกกว้าง 112px |

ถ้าเจอที่ล้น — **บอกมาได้เลย แก้ง่าย** (เพิ่มความกว้างที่ `width:` ของจุดนั้น)

## D4 · control ทุกตัวสูง 36px เท่ากัน *(phase C1)*

**เดิม:** ปุ่ม/ช่องกรอก 40px · ของเล็ก 32px · ของใหญ่ 48px
**ใหม่:** **36px ทั้งหมด** — `size="small"` ไม่เปลี่ยนความสูงอีกแล้ว

| หน้า | ดูตรงไหน |
|---|---|
| `/owner/products/addProducts` | ช่องกรอก · ตัวเลือกหมวดหมู่/หน่วยนับ · ช่องจำนวนสต็อก → **สูงเท่ากันหมด** ขอบบนล่างตรงกันพอดี |
| รายงานความคิดเห็น → ตั้งค่าหัวข้อรีวิว | แถว "ชื่อหัวข้อ(ไทย)" + "(อังกฤษ)" + ปุ่ม "เพิ่มหัวข้อ" — **3 อันสูงเท่ากัน** (เดิมปุ่มเตี้ยกว่า) |
| จัดการข้อมูลสินค้า | แถบเครื่องมือ — ช่องค้นหา · ตัวเลือกเรียง · ปุ่มสลับมุมมอง → สูงเท่ากัน |
| หน้าใดก็ได้ที่มีตาราง | ปุ่ม "แก้ไข"/"ลบ" ในแถว — **สูงขึ้นจากเดิม 32 → 36** แถวจะหนาขึ้นเล็กน้อย |

> ปุ่มในหน้าขายหน้าร้าน (POS) **ไม่เปลี่ยน** — ยังใหญ่ (44–54px) เพราะต้องกดด้วยนิ้วบนจอสัมผัส — เป็นข้อยกเว้นที่ตั้งใจ

## D5 · ปุ่มกระดิ่งกับแฮมเบอร์เกอร์เล็กลง 5.5px *(phase C2)*

49.5px → **44px** — เดิมเขียนหน่วยผิด (`2.75rem` นึกว่า 44px แต่ที่ฐาน 18 คือ 49.5px)

| ดูตรงไหน | ต้องเป็นยังไง |
|---|---|
| ปุ่มกระดิ่งมุมขวาบน (ทุกหน้า) | ยังกดง่าย ไม่เบี้ยวกับชื่อผู้ใช้ข้าง ๆ |
| ปุ่มแฮมเบอร์เกอร์ (ย่อหน้าจอให้แคบ) | ยังกดง่ายบนมือถือ |
