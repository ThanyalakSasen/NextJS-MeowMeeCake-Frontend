## ทำไมเลือก `gray-500` ไม่ใช่ `gray-600`

| คลาส | คอนทราสต์ | ผล |
|---|---|---|
| `gray-400` (เดิม) | 2.54:1 | ❌ ตก |
| **`gray-500` (ที่เลือก)** | **4.83:1** | ✅ ผ่าน — **อ่อนที่สุดที่ยังผ่าน** |
| `gray-600` | 7.56:1 | ✅ ผ่าน แต่เข้มจนใกล้ข้อความหลัก |

เลือก `gray-500` เพราะ **เปลี่ยนหน้าตาน้อยที่สุดเท่าที่ยังผ่านมาตรฐาน** และโปรเจกต์ใช้ `gray-500`
กับข้อความรองอยู่แล้ว **159 จุด** — การเปลี่ยนมาใช้ค่าเดียวกันจึงทำให้สอดคล้องกันมากขึ้น ไม่ใช่เพิ่มค่าใหม่

> ถ้าดูแล้วรู้สึกยัง**อ่อนเกินไป** เปลี่ยนเป็น `gray-600` ได้ทั้งโปรเจกต์ด้วยคำสั่งเดียว — บอกได้เลย

#### 1. จัดการข้อมูลสูตร — **6 จุด (เยอะสุดในระบบ)**

**เข้าหน้านี้:** sidebar → **การผลิต & วัตถุดิบ** → **จัดการข้อมูลสูตร**
`/owner/recipes`

**ดูตรงไหน:** การ์ดสูตรแต่ละใบ

| ตำแหน่ง | ข้อความที่เปลี่ยนสี |
|---|---|
| ใต้ชื่อสูตร | ชื่อสินค้าที่ผูกอยู่ |
| กลางการ์ด | หัวข้อ "ส่วนประกอบที่ใช้" |
| กลางการ์ด | "ยังไม่มีวัตถุดิบ" (สูตรที่ยังว่าง) |
| รายการวัตถุดิบ | ปริมาณ + หน่วย ทางขวา |
| ท้ายการ์ด | "อัปเดตเมื่อ …" |
| แท็บสูตรส่วนประกอบ | คอลัมน์ "ยังไม่ถูกใช้" และวันที่อัปเดต |

**แล้วคลิกสูตรเพื่อเปิดแผงรายละเอียด** — อีก 4 จุด: ป้ายสรุปด้านบน · "ยังไม่มีวัตถุดิบ" · "ยังไม่มีขั้นตอน" · เวลาของแต่ละขั้นตอน

#### 2. คำพ้องค้นหา — **5 จุด**

**ดูตรงไหน:** กล่อง **"ทดสอบการค้นหา"** ฝั่งขวา — พิมพ์คำอะไรก็ได้แล้วดู

| ตำแหน่ง | ข้อความ |
|---|---|
| ในช่องค้นหา | ไอคอนแว่นขยาย |
| ใต้ช่อง | "ไม่ได้ใช้กลุ่มคำพ้อง" |
| ระหว่างค้นหา | "กำลังค้นหา…" |
| ไม่เจอผล | "ไม่พบสินค้า" |
| ในผลลัพธ์ | ชื่อสินค้าภาษาอังกฤษ (ต่อท้ายชื่อไทย) |

#### 3. รายงานความคิดเห็น — **4 จุด (+ อีก 4 ในหน้าย่อย)**

**เข้าหน้านี้:** sidebar → **ภาพรวม** → **รายงานยอดขาย & ความคิดเห็น** → **รายงานความคิดเห็น**

|---|---|

| **กล่องตอบกลับ** (ในแผงขวา) | คำว่า "แม่แบบ" · จำนวนครั้งที่ใช้ · ตัวนับอักษร · เวลาที่ตอบ |

**แล้วไปหน้าย่อย:** ปุ่ม **ตั้งค่าหัวข้อรีวิว** → อีก 3 จุด (คำอธิบาย "ทำงานยังไง" · ตัวอย่าง · ชื่อหัวข้อภาษาอังกฤษ)

#### 4. บันทึกการทำงานของพนักงาน — **3 + 4 จุด**

## สิ่งที่ต้องรายงานถ้าเจอ

| อาการ | แปลว่า |
|---|---|
| ข้อความรอง**เข้มเท่าข้อความหลัก** จนแยกไม่ออก | เปลี่ยนมากเกินไป — อาจต้องถอยบางจุด |
| ข้อความ**ยังอ่านไม่ออก**ตอนหรี่จอ | ยังอ่อนไป — ต้องขยับเป็น `gray-600` |
| ไอคอน**ดูหนักผิดปกติ** | จุดนั้นควรแยกออกจากกฎ |
| **ข้อความตัวอย่าง (placeholder) ดูเหมือนข้อความที่กรอกแล้ว** | ช่องนั้นต้องใช้โทนอ่อนกว่า |

จดชื่อหน้า + ตำแหน่ง + อาการ แล้วแจ้ง จะแก้เฉพาะจุดได้

---

## ที่ **ไม่** ได้แก้ และทำไม

`border-gray-400` ใน 6 จุด — เป็น **สีขอบตอนเอาเมาส์ชี้** (hover) ของกรอบประ ไม่ใช่สีข้อความ
มาตรฐาน WCAG เรื่องคอนทราสต์ของกราฟิกใช้กับ**ขอบที่สื่อความหมายจำเป็น** ไม่ใช่เอฟเฟกต์ตอน hover
และ `gray-400` ในบทบาทนี้ไม่ได้ทำให้ใครอ่านอะไรไม่ออก

## ผลที่ได้

| | |
|---|---|
| `text-gray-400` ในโปรเจกต์ | **0 จุด** (จาก 106) |
| กฎ `no-gray-400` | ✅ **ปิดสนิท** — baseline = 0 เพิ่มกลับมาไม่ได้แล้ว |
| กฎ UI ทั้งหมด 4 ข้อ | ✅ **ปิดสนิททั้งหมด** |

> **หมายเหตุ:** กฎนี้ถูกขยายให้ดัก `placeholder-gray-400` (syntax เก่า) ด้วย หลังพบว่าของเดิมหลุดรอดมาได้
> และ `THEME.md` §4.1 เพิ่มตารางคอนทราสต์ครบทุกระดับแล้ว คนถัดไปจะไม่ต้องเดาว่าควรใช้เทาระดับไหน
